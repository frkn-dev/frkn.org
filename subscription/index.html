              Нужна помощь
              

                

                  
Что нужно

                  
    
                    
  • Свежий VPS с root-доступом: Ubuntu/Debian или Arch.
    • 
                    
  • Открытые порты: UDP 51821 (своя нода), UDP/TCP 443 (hysteria2), UDP 51820 (AmneziaWG).
    • 
                    
  • ~1 ГБ RAM и 5 ГБ диска.
    • 
                    
  • Нода обслуживает только твой аккаунт — другие пользователи к ней не подключаются.
    • 
                  

                

                

                  
Что будет дальше

                  
    
                    
  1. Скрипт поставит ноду и зарегистрирует её в твоём шарде.
    2. 
                    
  2. Обнови подписку в приложении Dopamine.
    3. 
                    
  3. В списке появится строка «<Страна> | Selfhosted» с протоколами.
    4. 
                    
  4. Подключись через неё: выходной IP будет IP твоего сервера.
    5. 
                  

                

                

                  
Если что-то не так

                  
    
                    
  • Порт 51821 занят — перезапусти с другим:
    curl -fsSL https://frkn.org/install | sudo PEER_PORT=51822 bash -s -- --token inst_…
    • 
                    
  • Ноды нет в списке — обнови подписку; лог: journalctl -u fnode -n 50.
    • 
                    
  • Запустить ещё раз — можно, повтор безопасен: ключи, интерфейсы и NAT не дублируются.
    • 
                    
  • Удалить ноду — кнопка удаления в карточке сервера выше.
    •

Конфиг для роутера

          
AmneziaWG-конфиг для роутера или другого устройства без приложения Dopamine. Ключ создаётся в браузере: в api уходит только публичная часть, приватный ключ остаётся в скачанном файле.

          

            Мы не храним приватный ключ. Если файл потеряется,
            восстановить его нельзя — останется создать новый конфиг, а
            старый перестанет работать после отзыва.
          


          

            

              
              
            

            

              
              
            

            

              
              
            

            

            
          


          

            

              Сохрани файл: приватный ключ показывается один раз и у нас не
              хранится. Потеряешь — останется создать новый конфиг.
