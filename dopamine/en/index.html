4.8.14.192
Android, iOS, macOS, Linux, Windows
  • Linux: the x64 installer is back — the bundle now carries the libraries only QML plugins need (libQt6ShaderTools, libxcb-cursor), so the app no longer crashes on the first screen.
  • Sharing the log no longer crashes the app on iOS.
  • Android: a Hysteria2 tunnel to a node reached by name no longer dies on the first packet — the dial address is pinned while the TLS name (SNI) stays the one the certificate was issued for.
  • iOS: the build is signed with the app-group profile, so settings sync between the app and the network extension.
4.8.14.190
Android, iOS, macOS, Windows
  • The server status dot no longer disappears when ping values are off: it is always there, grey until the probe lands.
  • Ping digits show only with the “Show server ping values” option on, and a row that has not been probed yet no longer reads “offline”.
  • The ping-measure button hides while the tunnel is up — measuring through it would describe the exit, not the server you picked.
  • Grey “not measured yet” dots are gone while the tunnel is up: probing is off there, so they would never fill in.
4.8.14.187
Android, iOS, macOS, Windows
  • “Privacy is our Religion” is now on the main screen, like on the site.
  • Server list: the “i” button opens a help screen — what the list is, how the protocols differ, how to switch them and where the traffic goes.
  • Protocol icons: AmneziaWG, WireGuard, VLESS, White Elephant (CDN), Hysteria2.
  • The ↓/↑ speed line is back on the main screen — it comes with the pings option.
  • Settings: “Subscriptions” is now “Subscription”.
  • Every interface string translated into English, Russian and Ukrainian.
  • When an exit is down the app never silently switches the country — the help screen says so.
4.8.14.186
Android, iOS, macOS, Linux, Windows
  • New connection model: servers are grouped by pool, the tunnel is built on first connect — the list loads instantly.
  • Super Duper plan: traffic packages sold separately from the base subscription term.
  • Speed test: every protocol of the pool, ping and download without connecting.
  • The home server card matches the site: a large name, a coloured ping dot, speed on the right.
  • Long server names no longer shrink or truncate — they wrap to a second line.
  • Subscription traffic in Settings matches the cabinet total.
  • Light theme: the card border and settings icons are readable.

Android, iOS, macOS, Linux, Windows

  • The refresh button reloads only the selected subscription; with "All" it reloads everything.

Why Dopamine

Privacy & access

No email, no accounts

Anonymous one-tap access: we collect no email, no logs, no personal data.

Censorship resistance

VLESS Reality, XHTTP via CDN, gRPC and AmneziaWG with packet obfuscation — indistinguishable from regular HTTPS to DPI.

Hysteria2

A fast QUIC-based protocol built for unstable networks.

Open source

The source is public under GPLv3: anyone can check our code.

Your own servers

Connect your own servers. Guide.

Traffic control

Flexible split tunneling

VPN only for selected sites and services — or the other way around, "everything except selected". Applied on reconnect.

Ready-made service presets

Ozon, banks and more: one checkbox instead of a manual domain list.

Suggest a service

AmneziaWG Mobile

A separate profile tuned for mobile networks and battery life.

Control & transparency

Auto-select

Finds the best server and connects to it.

Live server checks

Availability and latency for every server right in the list: green/yellow/red indicator, with exact pings if you want them.

Honest connection status

The connection is confirmed by a real handshake, not just by the tunnel being up.

Platform

iOS, macOS, Windows, Android and Linux

One account and the same experience on every device.

Russian, English, Ukrainian

Fully localized interface.

Kill Switch

Traffic never leaks outside the tunnel if the connection drops.
