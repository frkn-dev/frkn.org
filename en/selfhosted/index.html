Your own VPS node

Buy an Ubuntu box, SSH in, paste one command — get AmneziaWG + AmneziaWG Mobile + Hysteria2 and the fnode agent. Your node stays out of shared FRKN pools.

  1. VPS

    You need a normal VPS:

    • Ubuntu 22.04 or 24.04
    • root SSH access
    • public IP (optional domain → that IP for Hysteria2)

  2. Token

    Get a one-time inst_… token (we issue it for now; later — a cabinet button). Token lives about an hour.

  3. Command

    SSH in: ssh root@YOUR_IP. Paste the command, replace inst_YOUR_TOKEN with yours:

    curl -fsSL https://beta.frkn.org/install | bash -s -- --token inst_YOUR_TOKEN

    Installer is on beta: beta.frkn.org/install. Do not use old frkn.org/install links.

  4. Wait and check

    Takes a few minutes (packages, AWG kernel, fnode binary). No red errors at the end. Verify:

    systemctl status fnode --no-pager

    Expect active (running). If it failed — paste the output to support.

optional

What to install

  • no flag — everything (full): awg0 + awg1 + hysteria2 + fnode
  • AmneziaWG only: --profile awg
  • Hysteria2 only: --profile hysteria2 (needs a DNS A record for the hostname)
curl -fsSL https://beta.frkn.org/install | bash -s -- --token inst_… --profile awg

If it breaks

  • Not Ubuntu 22/24 → reinstall a clean image and retry.
  • Not root → sudo -i and try again.
  • Token expired / already used → ask for a new inst_….
  • Hysteria2 cert errors → point a DNS A record at this machine’s IP.
